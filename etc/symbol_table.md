# Таблица символов для test.c

Таблица сформирована в порядке, в котором переменные регистрируются семантическим
анализатором (`semantic.cxx`, функция `addSymbol`) при обходе AST: сначала параметры
из прототипа `calculate`, затем локальные переменные `main` (в порядке объявления,
включая переменную цикла `for`), затем параметры определения `calculate` (повторно
не добавляются, так как уже зарегистрированы прототипом).

| Имя       | Тип | Область видимости | Объявлена | Инициализирована | Строка объявления |
|-----------|-----|--------------------|-----------|-------------------|--------------------|
| a         | int | calculate          | +         | +                 | 6 (прототип) / 39 (определение) |
| b         | int | calculate          | +         | +                 | 6 (прототип) / 39 (определение) |
| x         | int | main               | +         | +                 | 10                  |
| y         | int | main               | +         | +                 | 11                  |
| result    | int | main               | +         | +                 | 12                  |
| i         | int | main               | +         | +                 | 25                  |
| counter   | int | main               | +         | +                 | 31                  |

## Пояснения к столбцам

**Имя** — идентификатор переменной (или формального параметра функции).

**Тип** — тип данных, объявленный в AST для соответствующего узла `VAR_DECL` / `PARAM`.
В тестовой программе все переменные имеют тип `int`.

**Область видимости** — имя функции, в которой переменная объявлена (`scope` в
структуре `Symbol`). Для `a` и `b` это `calculate`: оба её формальных параметра
видны только внутри тела (и сигнатуры) этой функции. Переменные `x`, `y`, `result`,
`i`, `counter` принадлежат области видимости `main`. Переменная цикла `i`,
объявленная в заголовке `for`, согласно реализации анализатора добавляется в ту же
область видимости, что и охватывающая функция (`currentFunc` не меняется внутри
блоков `if`/`for`/`while`), то есть фактически в `main`, а не в собственную
вложенную область.

**Объявлена** — отметка `+`, если для идентификатора был успешно вызван `addSymbol`.
Повторных объявлений в одной и той же области видимости в данной программе нет,
поэтому ни один идентификатор не помечен как ошибочный.

**Инициализирована** — отметка `+`, если переменной присвоено значение либо при
объявлении (есть узел `INIT`), либо позже оператором присваивания
(`sym->initialized = true` в `visitAssign`). Параметры функций (`a`, `b`) в
реализации анализатора всегда считаются инициализированными, так как получают
значение при вызове функции (`addSymbol(pName, pType, name, true, pLine)`).
Переменные `x`, `y`, `result`, `i`, `counter` инициализируются непосредственно при
объявлении (`int x = 10;` и т.д.), поэтому также помечены `+`.

**Строка объявления** — номер строки в исходном файле `test.c`, на которой находится
объявление. Для `a` и `b` указаны две строки, так как идентификатор формально
встречается дважды: в прототипе функции (строка 6) и в её определении (строка 39).
Семантический анализатор не считает это повторным объявлением — параметры
прототипа и определения согласованно совпадают, и при разборе тела функции
`addSymbol` для них возвращает `false`, что в коде явно не считается ошибкой.
