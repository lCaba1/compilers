## Правила разделения лексем

| Тип лексемы         | Чем может отделяться                                              |
|---------------------|-------------------------------------------------------------------|
| Ключевые слова      | Пробел, `\t`, `\n`, разделители `( ) { } ; ,`                   |
| Идентификаторы      | Пробел, `\t`, `\n`, разделители, операторы                       |
| Числовые константы  | Пробел, `\t`, `\n`, разделители, операторы                       |
| Строковые константы | Ограничены кавычками `"..."` — сами являются границей            |
| Операторы           | Могут примыкать к операндам без пробелов (`x+y`, `i++`)          |
| Разделители         | Сами являются границей лексемы, пробелы не нужны                 |

> Пробельные символы (пробел, `\t`, `\n`) являются разделителями но не токенами — они пропускаются.
